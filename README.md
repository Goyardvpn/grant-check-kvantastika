# Grant Check by Квантастика

Адаптивный одностраничный MVP для презентации специального предложения на обучение.

## Запуск
Откройте `index.html` в браузере или запустите через расширение Live Server в VS Code.

## В проекте
- Тёмный адаптивный интерфейс с glassmorphism.
- Поле ввода школы и анимированный демонстрационный сценарий.
- Экран предложения: 270 000 ₽ за 36 месяцев.
- Арифметический эквивалент: 270 000 / 36 = 7 500 ₽ в месяц.
- Пояснение, что предложение финансируется школой Квантастика, а не государством.

## Важно перед публикацией
Проверка пока демонстрационная: она не обращается к базе школ, API или CRM и не подтверждает право конкретной семьи на предложение. Подключите утверждённый источник данных и замените контактный адрес `hello@kvantastika.ru` на проверенный адрес команды. Подтвердите цену и условия у ответственного сотрудника.
