# Grant Check — демонстрация специальных условий

Одностраничная презентационная страница: короткая анимация проверки, затем экран результата с условиями предложения.

## Что показывает страница
- Результат: «Грант доступен».
- Тариф «Премиум»: 270 000 ₽ за 36 месяцев.
- Платёж: 7 500 ₽ в месяц (270 000 / 36).
- Иллюстрация условий с тарифами «Оптимальный» и «Премиум».

## Запуск
Откройте `index.html` в браузере или используйте GitHub Pages.

## Важно
Анимация демонстрационная: сайт не подключён к базе школ, CRM или государственным реестрам и не проверяет фактическое право конкретной семьи на финансирование. Условия предложения необходимо подтверждать у школы. Это специальное предложение школы, а не государственная выплата. Иллюстрация `grant-offer.svg` — векторная реконструкция предоставленного референса.
