# Grant Check — презентационная страница

Одностраничный лендинг в стилистике онлайн-школы с отдельным демонстрационным экраном результата.

## Структура
- `index.html` — лендинг, направления обучения и форма заявки.
- `styles.css` — адаптивный дизайн.
- `app.js` — валидация формы и отправка данных в Google Apps Script.
- `Code.gs` — серверный обработчик, добавляющий заявки в Google Таблицу.
- `result.html` — демонстрационный экран предложения.
- `grant-offer.svg` — иллюстрация тарифов.

## Подключение Google Таблицы

1. Создайте новую Google Таблицу.
2. Скопируйте ID таблицы из URL: часть между `/d/` и `/edit`.
3. Откройте [Google Apps Script](https://script.google.com/), создайте проект и вставьте содержимое файла `Code.gs`.
4. Вставьте ID таблицы в `SPREADSHEET_ID` вместо `PASTE_GOOGLE_SPREADSHEET_ID_HERE`.
5. Сохраните проект. Запустите публикацию: **Deploy → New deployment → Web app**.
6. Выберите выполнение от имени владельца скрипта и доступ для пользователей, которым разрешено пользоваться формой (для публичной страницы потребуется Anyone). Подтвердите запрашиваемые Google разрешения.
7. Скопируйте URL веб-приложения, заканчивающийся на `/exec`.
8. В `app.js` замените `PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE` на этот URL.
9. Опубликуйте обновлённый сайт и отправьте тестовую заявку. В таблице автоматически появится лист `Заявки` с заголовками и новой строкой.

Официальная инструкция Google: https://developers.google.com/apps-script/guides/web

## Важно перед публичным запуском

- Сейчас ссылка на политику в форме — заглушка `PRIVACY_POLICY_URL`. Замените её на реальную опубликованную политику обработки персональных данных вашей организации. Без этого не запускайте сбор реальных заявок.
- Укажите в политике оператора персональных данных, цели и правовые основания обработки, перечень данных, срок хранения, порядок отзыва согласия и контакты оператора. Проверьте применимые требования законодательства и настройки локализации хранения данных с ответственным за персональные данные.
- Форма собирает имя, фамилию, email, телефон и адрес школы только после явного согласия пользователя. Не собирайте лишние сведения.
- Доступ к Google Таблице должен быть ограничен сотрудниками, которым действительно нужны заявки. Не публикуйте таблицу по ссылке.
- При использовании публичного Apps Script URL защита от спама ограничена. Для промышленного использования добавьте серверную защиту/лимиты и мониторинг.
- Браузерный запрос использует `no-cors`, поэтому страница не может прочитать ответ Apps Script и подтвердить фактическую запись. Проверьте тестовую строку непосредственно в Google Таблице.
- Анимация и надпись «Грант доступен» — демонстрационные. Адрес школы не проверяется по реестрам, а страница не подтверждает право конкретного человека на грант. Условия предложения необходимо подтверждать у школы. Это предложение школы, не государственная выплата.
- Дизайн вдохновлён общей визуальной подачей сайта школы, но не является копией его исходного кода или официальной страницей.
